# 🚀 Flowly – SaaS Product Landing Page

A modern, responsive SaaS product landing page built as part of **Trainlyze Frontend Development – Task 1 (Project 1)**.

Flowly is a business management platform landing page designed with a clean UI, attractive orange-and-white theme, interactive components, and responsive layouts.

## 🌐 Live Demo

**Live Website:** https://trainlyze-saas-landing-page.vercel.app/

## 📌 Project Overview

The goal of this project is to create a modern, production-style SaaS landing page featuring structured sections, pricing plans, interactive components, and mobile-friendly layouts.

## ✨ Features

- Responsive and sticky navigation bar
- Mobile hamburger menu
- Hero section with call-to-action buttons
- Dashboard preview UI
- Trusted brands section
- Six feature cards
- Three pricing plans
- Monthly and yearly pricing toggle
- Interactive FAQ accordion
- Call-to-action section
- Social media links
- Smooth scrolling navigation
- Responsive design for mobile, tablet, and desktop

## 🛠️ Technologies Used

- HTML5 – Semantic page structure
- CSS3 – Styling, Flexbox, Grid and Media Queries
- JavaScript – DOM manipulation and interactivity
- Font Awesome – Icons
- Google Fonts – Inter typography
- Vercel – Deployment
- Git & GitHub – Version control
